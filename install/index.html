Install the app

On your phone, tablet or computer — straight from this website.

  • Opens full screen from its own icon, like any app.
  • Works offline at the pitch once saved — no signal needed.
  • Shortcuts to the drill, carry timer, quiz and modules: long-press the icon on Android, or right-click it on a computer.
  • Updates itself whenever you are online. No app store, no account, nothing collected.

HOW TO INSTALL

iPhone and iPad

  1. 1Open this page in Safari (Chrome and Edge on iOS 16.4 or later work too).
  2. 2Tap Share — at the bottom on iPhone, at the top on iPad.
  3. 3Scroll down and tap Add to Home Screen.
  4. 4Tap Add. The app appears on your home screen.

Android

  1. 1In Chrome, tap Install when it appears, or tap menu → Install app (or Add to Home screen).
  2. 2Samsung Internet: menu → Add page to → Home screen. Firefox: menu → Install.
  3. 3Confirm. The app appears on your home screen and in your app list.

Windows, Mac, Linux, ChromeOS — Chrome or Edge

  1. 1Click Install on this page, or the install icon at the right end of the address bar.
  2. 2Chrome: menu ⋮ → Cast, save and share → Install page as app. Edge: menu ⋯ → Apps → Install this site as an app.
  3. 3It opens in its own window and can be pinned to the taskbar or Dock.

Mac — Safari

  1. 1Safari 17 or later (macOS Sonoma or newer): File → Add to Dock, or Share → Add to Dock.
  2. 2Click Add. The app sits in your Dock and Launchpad.

Firefox on a computer

  1. 1Firefox on computers cannot install web apps. Open this page in Chrome or Edge to install it — or keep using it here in the browser.

USE IT WITHOUT A SIGNAL

Every page and the 3D drill are saved on this device automatically. Pictures, sounds and films are saved as you open them — or all at once here.

Installing adds a shortcut that opens this website as an app; nothing is downloaded from an app store and nothing about you is collected. To remove it, delete it like any other app.
